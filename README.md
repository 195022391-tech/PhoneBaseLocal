# 投屏解包 / 本地投屏

可运行：**非商业手机基座 IPA** + **Electron 桌面端**。

## 快速开始

1. 安装手机 IPA：`安装包/PhoneBase-Local-v0.12.2.ipa`
2. 双击根目录 `启动本地投屏.bat`（内部用 PowerShell 进中文目录，避免 cmd 乱码）
3. 「扫描设备」或手动添加手机 IP（端口 `11019`）

本仓库只收录非商业本地基座；桌面端也只连接 `licenseRequired=false` 的设备。

## 目录

```
安装包/                         # 手机 IPA
应用/
  本地投屏-桌面端/               # Electron 桌面端
    主进程/  界面/  安装包/  脚本/
  本地基座-iOS/                  # Swift 源码（需 Mac）
  浏览器客户端/                  # 浏览器对照
文档/                           # 协议与地图
证据/                           # 原始 IPA、抓包
研究/                           # 拆包切片
重建/                           # 重建缺口清单
桌面载荷/                       # 官方桌面 payload（若在跑会占用）
```
